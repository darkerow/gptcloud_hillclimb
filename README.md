# Hill Garage

Самостоятельная браузерная игра на **Phaser 3 + Matter.js**, вдохновлённая классическими физическими гонками по холмам. Играть: https://darkerow.github.io/gptcloud_hillclimb/

## Версия 0.3 — игровой цикл и контент

- **32 транспорта:** внедорожник и моноколесо, мотоциклы, монстр-траки, трактор, автобус, спецтехника, грузовики, танк, багги, аэрокар, ракетомобиль и конструктор. У моделей различаются геометрия, масса, количество/радиусы колёс, мотор, запас топлива и поведение. Есть баланс моноколеса, воздушная подушка аэрокара и реактивная тяга.
- **30 трасс:** пригород, пустыня, Арктика, шоссе, Луна, лес, горы, пещера, Марс, побережье, грязь, вулкан, город, крыши, снежные склоны, завод, стройка, острова, болото, ночь, каньон, большие дюны, другая планета, ледник, пустошь, шахта, радужные холмы, американские горки, шторм и осень. Меняются рельеф, палитра, сцепление, гравитация, потолки, сопротивление воды/грязи и ветер.
- **Карьера:** монеты и кристаллы на трассе, покупка техники и трасс, 4 категории улучшений по 15 уровней, бонусы за полёт/сальто/этапы, отдельные рекорды для пары транспорт–трасса.
- **Топливо:** расход, канистры, индикатор остатка, остановка заезда при исчерпании топлива. Экран результатов и повторный старт вместо автоматического сброса.
- **Усилители:** нитро, запасная канистра и магнит; запас пополняется за заработанные монеты. Нет реальных платежей и рекламных заглушек.
- **Задания:** 12 достижений, испытание дня на заданной технике/трассе, ежедневный подарок. Награды выдаются однократно.
- **Свободный заезд:** вся техника и все трассы доступны без покупки; топливо бесконечно. Не меняет карьерные награды и рекорды.
- **Интерфейс:** гараж, выбор трассы, мастерская, магазин, задания, пауза, результаты и настройки; адаптация под телефон, планшет и компьютер.
- **Сохранения:** локальный прогресс, перенос прежних рекордов машины/моноколеса, экспорт/импорт JSON, безопасное поведение при отключённом хранилище.
- **Звуки:** синтезированные мотор, сигналы, монеты и опциональная мелодия, включаемые после взаимодействия. Собственных аудиофайлов не требуется.
- **Трасса без финиша:** догрузка участков впереди и удаление старых участков. Подвесные мосты продолжают встречаться после первых 2200 м. Камера сохраняет независимое сглаженное слежение.

## Управление

**D / →** — газ. **A / ←** — тормоз/назад; в воздухе эти кнопки меняют наклон.
**R** — повторный старт. **V** — гараж. **Esc / P** — пауза/продолжение.
**1** — нитро, **2** — топливо, **3** — магнит. На телефоне — педали и кнопки усилителей.

Впервые доступны внедорожник и моноколесо, пригород, 2500 монет и небольшой запас усилителей. Для немедленного знакомства со всем каталогом выбери «Свободный заезд».

## Запуск и сборка

Node.js 22:

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Проверка

```bash
npm test
npm run build
python -m pip install playwright==1.57.0
python -m playwright install chromium
python tests/smoke.py
```

Node-тесты проверяют экономику, сохранения, миграцию, ограничения покупок и улучшений, одноразовые награды и сглаживание камеры. Chromium проверяет меню и покупки, весь каталог на начальном участке, все трассы, каждый из пяти мостов на машине и моноколесе, расход топлива, усилители, изоляцию свободного режима, очистку мира и мультитач.

Это не проверка всех 960 сочетаний транспорта и трасс и не гарантия прохождения любой дистанции. Все артефакты скриншотов доступны в `Validate game` → `game-browser-screenshots`.

`Deploy game to GitHub Pages` публикует `main`. Новые изменения сначала проверяются в feature-ветке.

## Файлы

`catalog.js` — машины, трассы и баланс; `progression.js` — сохранения и экономика;
`vehicles.js` — физика/отрисовка; `world.js` — потоковая трасса, мосты и предметы;
`camera.js` — сглаживание; `interface.js`, `art.js`, `style.css` — интерфейс;
`main.js` — игровой цикл; `audio.js` — синтез звука.

## Границы реализации

Это самостоятельная реализация жанра, **не побайтовый или покадровый клон всех версий Hill Climb Racing 1**. Здесь собственные иллюстрации, звуки, названия части контента, трассы и баланс. Реклама, покупки за реальные деньги, облачные сохранения, онлайн-рейтинги, оригинальные материалы и все специальные механики коммерческого оригинала не перенесены. Карточки каталога соответствуют реализованным игровым моделям; несколько моделей разделяют базовую схему шасси.

Ориентир по основному игровому циклу: официальная страница Fingersoft — https://fingersoft.com/games/hill-climb-racing/
