# Phaser Hill Climb

Небольшой Hill Climb-подобный прототип на **Phaser 3 + Matter.js**.

## Что уже есть

- физическая машина: кузов + 2 колеса;
- подвеска на constraints;
- холмистая трасса;
- газ / задний ход;
- наклон машины в воздухе;
- камера, следующая за машиной;
- счётчик дистанции и рекорд;
- рестарт после переворота/падения;
- экранные кнопки для телефона.

## Управление

- **→ / D** — газ;
- **← / A** — задний ход / торможение;
- **R** — рестарт;
- на телефоне — кнопки слева/справа внизу.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

Затем открыть адрес, который покажет Vite.
