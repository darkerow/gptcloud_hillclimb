# Phaser Hill Climb

Hill Climb-подобная игра на **Phaser 3 + Matter.js** с выбором транспорта.

## Транспорт

- **Машина** — кузов, два ведущих колеса и подвеска.
- **Моноколесо** — одно ведущее колесо, отдельный физический райдер в шлеме и аркадная помощь с балансом на земле. В воздухе наклон контролируется педалями; при падении заезд начинается заново.

Перед стартом открывается гараж. Выбери карточку и нажми **«Поехали»**.
Кнопка **«Транспорт»** или клавиша **V** возвращает в гараж и ставит физику на паузу. Можно продолжить текущий заезд или начать новый на выбранном транспорте.

Выбор и отдельные рекорды машины/моноколеса сохраняются локально. Старый рекорд автоматически используется для машины. При недоступном localStorage игра продолжает работать без постоянных сохранений.

## Управление

- **D / →** — газ; **A / ←** — тормоз и задний ход.
- В воздухе эти же кнопки меняют наклон.
- **R** или **«Заново»** — новый заезд на текущем транспорте.
- **V / Esc** — гараж / продолжение заезда.
- На телефоне — экранные педали с поддержкой нескольких касаний.

## Разработка

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

`src/main.js` — сцена и трасса, `src/vehicles.js` — физика и отрисовка транспорта,
`src/garage.js` — адаптивный интерфейс, `src/storage.js` — сохранения.

## Проверка и публикация

`Validate game` собирает игру и проверяет её в Chromium: выбор, движение обоих видов транспорта, паузу, рестарт, сохранения, повторные переключения и мобильные педали. Скриншоты доступны в артефактах Actions.

Локальный запуск тестов после сборки:

```bash
python -m pip install playwright==1.57.0
python -m playwright install chromium
python tests/smoke.py
```

`Deploy game to GitHub Pages` публикует ветку `main`.
